# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of the project.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest         | :white_check_mark: |
| Older versions | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it through a public GitHub issue.

Instead, report it privately to the project maintainer through GitHub's private vulnerability reporting feature.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant logs, screenshots, or proof of concept
* A suggested fix, if available

You can expect an initial response within 7 days.

After receiving a report, the maintainer will investigate the issue, determine its severity and impact, and take appropriate action.

If the vulnerability is confirmed, a fix will be developed and released as soon as reasonably possible. The reporter will be kept informed about the progress of the resolution.

Please avoid publicly disclosing the vulnerability until a fix or mitigation is available.

## Security Considerations

This project is a trading engine and may interact with cryptocurrency exchanges and financial APIs. Never include API keys, private keys, passwords, authentication tokens, or other sensitive credentials in issues, logs, commits, or pull requests.

If credentials are accidentally exposed, revoke and rotate them immediately.
